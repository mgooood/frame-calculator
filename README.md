# Frame Calculator

A browser-based calculator for custom picture frame making.

Enter your artwork dimensions and wood stock measurements — get exact cut lengths, rabbet specs, glazing size, and material estimates instantly.

## Live Site

[https://mgooood.github.io/frame-calculator](https://mgooood.github.io/frame-calculator)

## What it calculates

- Frame opening size
- Glazing cut size (with 1/16" thermal clearance per side)
- Outer frame size (long-point to long-point for 45° miters)
- Cut list — 4 pieces with exact lengths
- Rabbet dimensions to route
- Material stack check (glazing + art + backing vs. rabbet depth)
- Total moulding needed in linear feet and board feet

## Stack

Plain HTML, CSS, and JavaScript — no build step, no dependencies.

## Usage

Open `index.html` in a browser, or visit the live site above.
